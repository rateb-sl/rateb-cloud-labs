# Security Policy

## Reporting a Vulnerability

This repository is a personal cloud-engineering learning portfolio. If you
discover a security issue in any script, policy, or configuration here,
**please do not open a public issue** — report it privately.

Preferred channels, in order:

1. **Private security advisory:** https://github.com/rateb-sl/rateb-cloud-labs/security/advisories/new
2. **Email the repository owner** (see profile for contact details)

I aim to respond within 7 days. If the issue involves a credential or
account, rotate the affected credential immediately and mention the
rotation in your report.

## Supported versions

This is a learning portfolio — there are no supported releases. All
commits on `main` are considered current.
